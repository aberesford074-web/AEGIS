AEGIS Sales OS

Forklift stock control for the Forklift Pro website.

Use the existing AEGIS Google Sheets CRM as the operating layer for truck details, stock status, media paths, and website inventory updates.

Control Centre

Add, edit, and publish truck stock

The stock manager is the working screen for Forklift Pro Solutions. Use it to add a truck, upload the main photo, update the local website inventory, and keep the Google Sheet stock table aligned.

Open stock manager -> Open stock sheet ->

Stock Sheet

Forklift Stock

Truck details live in the same AEGIS Google Sheet system as the CRM. The live sheet now has `Forklift Stock` and `Forklift Media` tabs.

  • Model, brand, type, power, capacity, lift height, price
  • Status: in-stock, sold, reserved, draft
  • Image paths for main photos and galleries
  • Public website inventory JSON export

Media Upload

Truck Photos

Photos upload into the Forklift Pro website media folder. The stock manager can attach the uploaded path to the truck and update the website inventory.

Open media upload ->

Workflow

How updates should work

1 Add or edit truck row in Google Sheets 2 Upload photos through AEGIS Sales OS 3 Paste media paths into the Sheet 4 Sync stock into the Forklift Pro website
